# Software Requirement Specification

## 1. Project Overview

The AI-Powered Student Support Assistant is a web-based student portal that allows college students to ask natural-language questions and receive intelligent, context-aware responses about academic and administrative information.

## 2. Functional Requirements

- Student login with email and password
- Student profile retrieval
- Attendance query support
- Marks and result query support
- Fee status query support
- Timetable access
- Assignment reminders
- Notices and announcements
- Hostel, faculty, placement, library, events, and holiday information
- Admin-style data management support for future extension

## 3. Non-Functional Requirements

- Fast response time
- Responsive UI
- Secure authentication design
- Extensible AI + RAG architecture
- 24×7 availability mindset

## 4. Use Cases

1. Student logs in using college email credentials.
2. Student asks: “What is my attendance?”
3. System selects the attendance intent and returns data from the backend.
4. Student asks an academic policy question.
5. System uses policy knowledge and returns the answer.
