# AI-Powered Student Support Assistant

An AI-powered full-stack student support system built using FastAPI, HTML, CSS, JavaScript, and Machine Learning.

## Features
- Student Login
- Attendance Management
- Marks & Results
- Fee Information
- Timetable
- Notices
- Placement Information
- AI Chatbot
- ML Intent Classification
- RAG-based Knowledge Retrieval

## Tech Stack
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQL
- Scikit-learn

## Installation

```bash
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```
